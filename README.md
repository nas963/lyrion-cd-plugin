# AudioCD za Lyrion

Plugin za Lyrion Music Server: CD plejer i snimanje albuma (cyanrip, FLAC, AccurateRip) sa automatskim prepoznavanjem diska, sviranjem iz RAM keša bez prekida i integracijom u Material Skin.

Instalacija jednom naredbom, na serveru:

```bash
curl -fsSL https://github.com/nas963/lyrion-cd-plugin/releases/latest/download/get.sh | sudo bash
```

Posle toga Lyrion sam ažurira plugin iz repozitorijuma `https://nas963.github.io/lyrion-cd-plugin/repo.xml`, kao bilo koji drugi plugin.
