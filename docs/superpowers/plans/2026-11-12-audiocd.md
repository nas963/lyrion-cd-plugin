# AudioCD – plan implementacije

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lyrion plugin AudioCD: očitavanje audio CD-a sa metapodacima i omotom, Play iz RAM keša i rip u FLAC preko cyanrip-a, sa stranicom u LMS-u/Material-u.

**Architecture:** Čiste Perl jedinice bez zavisnosti od LMS-a (DiscId, Config, Naming, Profiles, parseri metapodataka, MaterialBridge) se testiraju same. Tanke LMS jedinice (Plugin, Cache, Ripper, ProtocolHandler, Web, Menu, Settings) ih povezuju preko CLI/JSON-RPC komandi `audiocd ...`. Spoljni alati (`cd-paranoia`, `flac`, `cyanrip`, `cd-info`, `eject`) se pokreću kao procesi niskog prioriteta.

**Tech Stack:** Perl 5.38/5.40 (samo core + LMS moduli), LMS 9.1 API (`Slim::*`), JSON::PP, Digest::SHA, HTML/vanilla JS, bash, Python 3 za build paketa.

**Spec:** `docs/superpowers/specs/2026-11-12-audiocd-design.md`

## Global Constraints

- Ime: `AudioCD`, paket `Plugins::AudioCD::*`, prefs `plugin.audiocd`, log kategorija `plugin.audiocd`, CLI prefiks `audiocd`.
- Samo čist Perl, core moduli i moduli koje LMS nosi. Bez CPAN XS modula. JSON u čistim jedinicama: `JSON::PP`.
- Mora da radi na Perl-u 5.38 i 5.40 (`use strict; use warnings; use utf8;` u svakom fajlu, bez novih feature-a posle 5.36).
- Svaki spoljni proces: `nice -n 10 ionice -c3 <cmd>`. Nikad RT, nikad `audio.slice`.
- Alati se traže prvo u `/usr/bin`, pa `/bin`, pa `PATH` (na razvojnom serveru `/usr/local/bin` ima pokvaren `cd-paranoia`).
- Folder za rip-ove: pref `ripsDir` → `CD_RIPS_DIR` iz `/etc/audioos/audioos.conf` → iz `/usr/local/lib/audioos/defaults.conf` → `/var/lib/squeezeboxserver/CD-Rips`.
- Fajlovi rip-a 0644, folderi 0755. Nikad se ne prepisuje postojeći folder albuma.
- User-Agent: `AudioCD/<verzija> ( https://github.com/nas963/lyrion-cd-plugin )`. Nikakvi lični podaci ni u jednom zahtevu.
- MusicBrainz: najviše 1 zahtev/s. HTTP timeout 15 s.
- Drajv radi jednu operaciju u jednom trenutku (`cache` ili `rip`).
- Fajlovi u repou: LF završeci (`.gitattributes` `* text=auto eol=lf`).
- Tekstovi za korisnika u `strings.txt` (EN i SR), ne u kodu.
- Repo je javan: u njemu nema IP adrese servera, korisničkih imena ni putanje SSH ključa (skripte koriste SSH alias `lyrion`).

## Review Focus

1. **Disk izvađen ili zamenjen tokom keširanja/ripa** – posao se prekida, procesi ubijaju, privremeni fajlovi brišu, stanje prelazi u `empty`; stari disc ID ne sme da ostane prikazan. Test u Task 12 (`eject_event` tokom posla).
2. **Ne-ASCII metapodaci** (srpska latinica, japanski) u nazivima foldera, tagovima i argumentima procesa – UTF-8 bajtovi na disku, sečenje na granici znaka. Testovi u Task 4 i Task 9.
3. **Enhanced CD, data pesma i skrivena pesma pre prve (HTOA)** – disc ID mora biti tačan, data pesma se ne nudi za Play/rip. Testovi u Task 2 i Task 3.
4. **Gašenje/restart LMS-a dok radi proces** – `shutdownPlugin` ubija grupe procesa i briše `.part`/tmp; pri startu se brišu ostaci starih poslova. Test u Task 8 i Task 10.
5. **Dvostruki zahtevi** (Play dva puta, rip dok traje keširanje, dva plejera) – drugi zahtev dobija jasnu grešku ili se nadovezuje na isti keš, nikad dva procesa na drajvu. Test u Task 12.
